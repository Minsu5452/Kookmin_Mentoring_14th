# 국민대 연결고리 14기 멘토링

국민대학교 경영대학의 현업 동문 멘토링 프로그램 '연결고리' 14기에 멘티로 참여한 활동 기록입니다. 데이터 직군에서 일하는 동문 멘토와 4회에 걸쳐 진로와 취업 준비를 주제로 멘토링을 진행했습니다.

## 개요

| 구분 | 내용 |
| --- | --- |
| 프로그램 | 연결고리 14기 |
| 기간 | 2023.10 – 2023.11 |
| 기관 | 국민대학교 경영대학 |
| 팀 | 프로스펙터스 (3인) |
| 역할 | 멘티 |

## 활동 내용

| 회차 | 시기 | 주제 |
| --- | --- | --- |
| 1회차 | 2023.10 | 멘토·멘티 소개와 목표 설정, 학교생활·인턴·취업 경험 문답 |
| 2회차 | 2023.11 | 관심 기업 분석과 기업보고서 작성, 데이터 직군 취업 전략 |
| 3회차 | 2023.11 | 멘토 재직 회사 방문, 자기소개서 작성과 피드백 |
| 4회차 | 2023.11 | 활동 정리와 향후 계획 점검 |

## 자료

## 공개 범위

최종 보고서는 멘토와 팀원의 실명·학번·사진을 담고 있어 공개 저장소에는 포함하지 않았습니다.
